# 0042 · 接雨水

题目链接：https://leetcode.cn/problems/trapping-rain-water/

难度：困难 | 语言：Java | 标签：栈、数组、双指针、动态规划、单调栈

## 解题思路

一开始我将接雨水的部分考虑成一个整体了，后来才直到可以一个柱子一个柱子看，首先找到当前柱子左右两侧的最高柱子，两个柱子中较短的柱子减去当前位置柱子长度就是这根柱子上方的雨水量。然后当前位置往后挪动，如果遇到柱子长度大于左侧或右侧时，更新对应的当前左右两侧的最长柱子

## 代码

```java
class Solution {
    public int trap(int[] height) {
        int left = 0;
        int right = height.length - 1;

        int leftMax = 0;
        int rightMax = 0;
        int totalWater = 0;

        while (left <= right) {
            // 更新两端已经遇到的最高柱子
            leftMax = Math.max(leftMax, height[left]);
            rightMax = Math.max(rightMax, height[right]);

            if (leftMax <= rightMax) {
                totalWater += leftMax - height[left];
                left++;
            } else {
                totalWater += rightMax - height[right];
                right--;
            }
        }

        return totalWater;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(1)

## 踩过的坑

一开始我是准备从左到右找到比左侧高的右侧，然后计算两者之间的水量，但是没有考虑到如果右侧一直没有高于左侧的柱子，一样可以蓄水
