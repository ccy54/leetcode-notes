# 0025 · k个一组翻转链表

题目链接：https://leetcode.cn/problems/reverse-nodes-in-k-group

难度：困难 | 语言：Java | 标签：递归、链表

## 解题思路

这个方法是在两两交换链表中的节点这道题上的进一步，需要判断当前组是否满足k个节点，不满足则弹出。
这里的反转使用了之前的方法，设定previous和current，只是之前一开始设定previous为null，现在设定为下一组的第一个节点。
反转的重点就是记录当前组的前后两个节点，然后逐个反转，用current记录当前组的头节点，nextNode记录前面节点处理后的新的头节点，过程为：
ListNode nextNode=current.next;
current.next=previous;
previous=current;
current=nextNode;


## 代码

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode before = dummy;

        while (true) {
            // 1. 找本组第 k 个节点，确认节点数量足够
            ListNode end = before;

            for (int i = 0; i < k && end != null; i++) {
                end = end.next;
            }

            // 不足 k 个，剩余部分保持原样
            // 这里当不足k个时，触发上面的end!=null弹出，然后在下面这里触发if(end==null)，break
            if (end == null) {
                break;
            }

            // 2. 保存本组原头节点和下一组起点
            ListNode start = before.next;
            ListNode after = end.next;

            // 3. 反转本组的 k 个节点
            ListNode previous = after;
            ListNode current = start;

            for (int i = 0; i < k; i++) {
                ListNode nextNode = current.next;
                current.next = previous;
                previous = current;
                current = nextNode;
            }

            // 4. 接回前面的部分，并移动到本组新尾节点
            before.next = previous;
            before = start;
        }

        return dummy.next;
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(1)

## 踩过的坑

需要熟练反转链表的全部过程
