# 0025 · k个一组翻转链表

题目链接：https://leetcode.cn/problems/reverse-nodes-in-k-group

难度：困难 | 语言：Java | 标签：递归、链表

## 解题思路

这个是递归的方法，有从前往后和从后往前两种思路，如果从前往后处理，将previous设置为null，把每个组看成独立的个体进行翻转，然后使用head.next=后面处理的链表，这样连接起来。如果从后往前处理previous就是后面一组的第一个节点，然后再按照通用的方式进行翻转。

## 代码

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if (head == null || k == 1) {
            return head;
        }

        // 1. 检查是否有完整的 k 个节点
        ListNode after = head;

        for (int i = 0; i < k; i++) {
            if (after == null) {
                return head;
            }
            after = after.next;
        }

        // after 现在指向下一组的起点

        // 2. 反转当前组
        ListNode previous = null;
        ListNode current = head;

        for (int i = 0; i < k; i++) {
            ListNode nextNode = current.next;
            current.next = previous;
            previous = current;
            current = nextNode;
        }

        // 3. 原头节点变成组尾，接上后续部分的处理结果
        head.next = reverseKGroup(after, k);

        // previous 是当前组反转后的新头
        return previous;
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(n/k)，来自递归调用栈
