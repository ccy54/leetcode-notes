# 0138 · 随机链表的复制

题目链接：https://leetcode.cn/problems/copy-list-with-random-pointer/

难度：中等 | 语言：Java | 标签：哈希表、链表

## 解题思路

这个方法分成三步走
第一步：为原链表中的每一个节点在其后创建一个等值的新节点，注意node的移动
第二步：复制原链表中的random关系，新节点的random赋值为原节点的random的next，注意node的移动
第三步：恢复成两个单独的链表，单独创建一个newHead，赋值为head.next，然后获取node.next，将node.next重新指向原先的节点，即node.next.next，此时head和原本的head.next都指向head.next，即A和A的copy都指向B，判断A的copy的next是否为null，若不是，则将B的copy接到A的copy后面，若为null，则接上null，此时A指向B指向C，A的copy指向B的copy指向C，node=node.next使得node指针挪动到B

## 代码

```java
class Solution {
    public Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }
        for (Node node = head; node != null; node = node.next.next) {
            Node nodeNew = new Node(node.val);
            nodeNew.next = node.next;
            node.next = nodeNew;
        }
        for (Node node = head; node != null; node = node.next.next) {
            Node nodeNew = node.next;
            nodeNew.random = (node.random != null) ? node.random.next : null;
        }
        Node headNew = head.next;
        for (Node node = head; node != null; node = node.next) {
            Node nodeNew = node.next;
            node.next = node.next.next;
            nodeNew.next = (nodeNew.next != null) ? nodeNew.next.next : null;
        }
        return headNew;
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(1)

## 踩过的坑

这个的理解重点在于最后一步恢复成两个独立的节点
