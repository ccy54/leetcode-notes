# 0560 · 和为k的子数组

题目链接：https://leetcode.cn/problems/subarray-sum-equals-k/

难度：中等 | 语言：Java | 标签：数组、哈希表、前缀和

## 解题思路

最初的想法：可以从左向右遍历，将前面的值的所有可能组合存放在哈希表中吗？就是在哈希表中查找k和当前值的差值，若不在哈希表中就写入哈希表，若在的话就返回下标。存储的例子为，若num=[1,2,3,4]，在查看4时，哈希表中存放[1,2,3]存放1,2,3,3,5,6这样。
正确的想法：存储之前的前缀和，这样用现在的前缀和减去之前的前缀和能保证数组一定是连续的，
for(int num:nums){
            sum+=num;
            answer+=prefixCount.getOrDefault(sum-k,0);
            prefixCount.put(sum,prefixCount.getOrDefault(sum,0)+1);
        }
这里最关键的三步，第一步就是计算当前前缀和，第二部就是计算当前前缀和和目标值的差值有没有在之前的前缀和里出现，第三步就是将当前前缀和写入到哈希表中。

## 代码

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        // 前缀和 → 出现次数
        Map<Integer,Integer> prefixCount=new HashMap<>();
        prefixCount.put(0,1);
        int sum=0;
        int answer=0;
        for(int num:nums){
            sum+=num;
            answer+=prefixCount.getOrDefault(sum-k,0);
            prefixCount.put(sum,prefixCount.getOrDefault(sum,0)+1);
        }
        return answer;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(n)
