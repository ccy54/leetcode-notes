# 0021 · 合并两个有序链表

题目链接：https://leetcode.cn/problems/merge-two-sorted-lists/

难度：简单 | 语言：Java | 标签：递归、链表

## 解题思路

这个方法的思路就是把小于当前节点的节点全部连接起来，层层递归，最终从最后往最前开始排序
e.g.
1->2->5
1->4->6
第一轮：l1=l2, l1.next=mT(2,1), return l1
第二轮：l1>l2, l2.next=mT(2,4), return l2
第三轮：l1<l2, l1.next=mT(5,4), return l1
第四轮：l1>l2, l2.next=mT(5,6), return l2
第五轮：l1<l2, l1.next=mT(null,6), return l1
第六轮：l1==null, return l2

## 代码

```java
class Solution {
    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        if (l1 == null) {
            return l2;
        } else if (l2 == null) {
            return l1;
        } else if (l1.val <= l2.val) {
            l1.next = mergeTwoLists(l1.next, l2);
            return l1;
        } else {
            l2.next = mergeTwoLists(l1, l2.next);
            return l2;
        }
    }
}
```

## 复杂度

时间复杂度为O(m+n)，空间复杂度为O(m+n)，空间的开销主要来源于递归调用栈
