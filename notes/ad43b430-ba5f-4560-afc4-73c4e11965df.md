# 0234 · 回文链表

题目链接：https://leetcode.cn/problems/palindrome-linked-list/

难度：简单 | 语言：Java | 标签：栈、递归、链表、双指针

## 解题思路

这个解法用到了反转链表的方法，将后半段链表反转，得到一个新head，两个head同时往后比较每个节点的值，如果有不一样的就返回False。
怎么找到反转链表的开头：使用快慢两个节点同时从链表开头往后移动，快指针一次移动2步，慢指针一次移动1步，直到fast.next为null或者fast.next.next为null，此时slow.next就是反转链表的开头，使用反转链表函数反转后半段，然后从新旧head往后比较每个节点的val值

## 代码

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) {
            return true;
        }

        // 1. 找到前半段末尾
        ListNode slow = head;
        ListNode fast = head;

        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 2. 反转后半段
        ListNode secondHalf = reverse(slow.next);

        // 3. 从两部分的开头，逐个比较数值
        ListNode p1 = head;
        ListNode p2 = secondHalf;
        boolean result = true;

        while (p2 != null) {
            if (p1.val != p2.val) {
                result = false;
                break;
            }

            p1 = p1.next;
            p2 = p2.next;
        }

        // 4. 恢复后半段，并重新连接
        slow.next = reverse(secondHalf);

        return result;
    }

    // 使用循环反转，保证额外空间为 O(1)
    private ListNode reverse(ListNode head) {
        ListNode previous = null;
        ListNode current = head;

        while (current != null) {
            ListNode nextNode = current.next;
            current.next = previous;
            previous = current;
            current = nextNode;
        }

        return previous;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(1)

## 踩过的坑

一开始准备复制一份链表，然后对复制得到的链表进行反转，但是这样会产生额外的空间复杂度O(n)
