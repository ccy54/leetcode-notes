# 0128 · 最长连续序列

题目链接：https://leetcode.cn/problems/longest-consecutive-sequence/description

难度：中等 | 语言：Java | 标签：并查集、数组、哈希表

## 解题思路

使用哈希表存储数组，哈希表可以去除重复数字，然后检查每个数的前一个数在不在哈希表中，如果在的话这个数就不是起点，如果是起点从这个数往后数的大小++，连续序列的长度++，直到出现num+1不在哈希表的情况，然后将该连续序列长度和挡墙最长连续序列长度比较，看哪个更长。

## 代码

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> numbers = new HashSet<>();

        // 保存数字，同时去重
        for (int num : nums) {
            numbers.add(num);
        }

        int maxLength = 0;

        // 遍历去重后的集合
        for (int num : numbers) {
            // 有前一个数字，就不是序列起点
            if (numbers.contains(num - 1)) {
                continue;
            }

            int current = num;
            int length = 1;

            // 从起点向后寻找连续数字
            while (numbers.contains(current + 1)) {
                current++;
                length++;
            }

            maxLength = Math.max(maxLength, length);
        }

        return maxLength;
    }
}
```

## 复杂度

时间复杂度为 O(n)，额外空间复杂度为 O(n)

## 踩过的坑

一开始我准备先对数组进行内部排序，然后依次检查，但是忽略了题目要求时间复杂度为O(n)，如果排序，时间复杂度一般为O(nlog n)

## 我的收获

如果看到序列中有重复情况出现，而重复情况需要忽略时，我们就要采用哈希表
