# 0206 · 反转链表

题目链接：https://leetcode.cn/problems/reverse-linked-list

难度：简单 | 语言：Java | 标签：递归、链表

## 解题思路

递归法
一层一层局部构造循环链表，然后将顺序断开。
例如链表为1->2->3->4
通过ListNode newHead = reverseList(head.next)层层递归，递归到节点3时，ListNode newHead = reverseList(head.next)中的head.next为节点4，输入到reverseList中满足head.next==null，返回，此时head为节点3，head.next为节点4，head.next.next = head让节点4的下一个节点变成节点3，即形成循环链表3->4，4->3，再使用head.next = null断开3->4，只剩下4->3，此时链表变成1->2->4->3，newHead为节点4，

## 代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
```

## 复杂度

时间复杂度是 O(n)，额外空间复杂度是 O(n)

## 踩过的坑

1 → 2 → 3 → 4 → null，若3 → 4关系反转变成4 → 3，不会影响其他节点的关系，2.next仍然是3
