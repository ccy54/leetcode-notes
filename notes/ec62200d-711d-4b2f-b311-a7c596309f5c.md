# 0141 · 环形链表

题目链接：https://leetcode.cn/problems/linked-list-cycle/

难度：简单 | 语言：Java | 标签：哈希表、链表、双指针、floyd判圈算法

## 解题思路

使用哈希表存储链表中的节点，若节点在哈希表中则判断为有环
if (!seen.add(head)) {
                return true;
            }
seen.add(head)，若head不在哈希表中，则添加head并返回true，若head在哈希表中，则不重复添加，返回false

## 代码

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        Set<ListNode> seen = new HashSet<ListNode>();
        while (head != null) {
            if (!seen.add(head)) {
                return true;
            }
            head = head.next;
        }
        return false;
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(n)，空间复杂度的开销为哈希表
