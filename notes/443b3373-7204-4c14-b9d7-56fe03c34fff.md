# 0024 · 两两交换链表中的节点

题目链接：https://leetcode.cn/problems/swap-nodes-in-pairs/

难度：中等 | 语言：Java | 标签：递归、链表

## 解题思路

一开始我只想到用三个节点，但是这样节点交换流程会变复杂，而且容易搞错，后来知道用四个节点，分别存储前一个节点，交换的两个节点，和后一个节点，通过
ListNode a = first.next;
ListNode b = a.next;
ListNode last = b.next;

// 交换并接回前后两部分
a.next = last;
b.next = a;
first.next = b;
这个流程来交换两个节点，然后通过first获取下一对节点的位置

## 代码

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode first = dummy;

        // 后面至少有两个节点，才可以交换
        while (first.next != null && first.next.next != null) {
            ListNode a = first.next;
            ListNode b = a.next;
            ListNode last = b.next;

            a.next = last;
            b.next = a;
            first.next = b;

            // A 现在是已交换部分的最后一个节点
            first = a;
        }

        return dummy.next;
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(1)
