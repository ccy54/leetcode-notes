# 0206 · 反转链表

题目链接：https://leetcode.cn/problems/reverse-linked-list

难度：简单 | 语言：Java | 标签：递归、链表

## 解题思路

这个方法是将当前节点和当前节点的next断开，用一个新链表存储当前节点的next，然后反转当前节点的连接，让当前节点的next指向之前的节点，当前节点处理完成后，当前节点和当前节点的next变成previous，current指向后一个节点

## 代码

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode previous = null;
        ListNode current = head;

        while (current != null) {
            // 保存原来的下一个节点
            ListNode nextNode = current.next;

            // 反转当前节点的连接
            current.next = previous;

            // 推进到下一个待处理节点
            previous = current;
            current = nextNode;
        }

        return previous;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(1)
