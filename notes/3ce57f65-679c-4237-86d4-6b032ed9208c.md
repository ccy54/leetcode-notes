# 0019 · 删除链表的倒数第N个结点

题目链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list

难度：简单 | 语言：Java | 标签：链表、双指针

## 解题思路

这个方法的主要思路就是找到倒数第n+1个节点，再跳过待删除节点。找到倒数第n+1个节点有两种方法，一种就是先得到整个链表长度，然后移动head，另一种是使用两个相差n步的指针，当前一个指针.next为null时，后一个指针指向删除节点的前一个结点。
使用第一种方法的特殊情况：当链表要删除第一个节点时，没有前一个节点，因此使用dummy占位法，创建一个节点，节点的next指向head，最后返回dummy.next

## 代码

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
         ListNode dummy = new ListNode(0);
        dummy.next = head;

        // 第一次遍历：统计链表长度
        int length = 0;
        ListNode current = head;

        while (current != null) {
            length++;
            current = current.next;
        }

        // 第二次遍历：找到待删除节点的前一个节点
        current = dummy;

        for (int i = 0; i < length - n; i++) {
            current = current.next;
        }

        // 跳过待删除节点
        current.next = current.next.next;

        return dummy.next;
    }
}
```

## 复杂度

时间复杂度O(L)，空间复杂度O(1)

## 踩过的坑

没有考虑到如果删除的是第一个节点怎么办
