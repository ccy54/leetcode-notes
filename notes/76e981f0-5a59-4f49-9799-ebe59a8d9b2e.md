# 0011 · 盛最多水的容器

题目链接：https://leetcode.cn/problems/container-with-most-water

难度：中等 | 语言：Java | 标签：贪心、数组、双指针

## 解题思路

使用两个指针分别指向最左侧和最右侧吗，两个指针指向的线的x坐标差值乘较短线的y坐标得到当前水量，由于向内移动，横轴变短，所以如果纵向也变短，当前水量肯定小于之前计算的水量，可以直接跳过，每次移动y坐标较小的指针，将每次得到的水量与当前最大水量进行对比

## 代码

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxWater = 0;

        while (left < right) {
            int width = right - left;
            int shorterHeight = Math.min(height[left], height[right]);
            int water = width * shorterHeight;

            maxWater = Math.max(maxWater, water);

            // 移动较短的一侧，寻找更高的线
            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxWater;
    }
}
```

## 复杂度

时间复杂度O(n)，额外空间复杂度O(1)
