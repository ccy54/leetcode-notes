# 0138 · 随机链表的复制

题目链接：https://leetcode.cn/problems/copy-list-with-random-pointer/

难度：中等 | 语言：Java | 标签：哈希表、链表

## 解题思路

这个题的思路是使用哈希表来存储旧链表和新链表中节点的对应关系。
使用两次遍历，第一次创建和旧链表节点值相等的新链表，并将对应关系存储在哈希表中。
第二次找到节点之间的对应关系，先找到当前节点的next或random节点，再使用哈希表转化成新链表中的对应节点

## 代码

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public Node copyRandomList(Node head) {
        Map<Node, Node> copies = new HashMap<>();

        Node current = head;

        // 第一遍：创建节点，记录“原节点 → 新节点”
        while (current != null) {
            copies.put(current, new Node(current.val));
            current = current.next;
        }

        current = head;

        // 第二遍：连接新节点
        while (current != null) {
            Node copy = copies.get(current);

            copy.next = copies.get(current.next);
            copy.random = copies.get(current.random);

            current = current.next;
        }

        return copies.get(head);
    }
}
```

## 复杂度

时间复杂度O(n)，空间复杂度O(n)，空间复杂度主要来源于哈希表的创建

## 踩过的坑

一开始我只想到使用哈希表存储节点之间的random关系，后面才知道可以直接存储新链表和旧链表节点一一对应的关系，而next和random关系天然包含在旧链表中

## 我的收获

看到需要找对应关系的，就使用哈希表
