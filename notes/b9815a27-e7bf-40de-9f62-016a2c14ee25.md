# 0141 · 环形链表

题目链接：https://leetcode.cn/problems/linked-list-cycle/

难度：简单 | 语言：Java | 标签：哈希表、链表、双指针、Floyd判圈算法

## 解题思路

对环形链表使用反转链表，若节点current能回到最开始的head，则证明该链表为环形链表

## 代码

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        if (head == null) {
            return false;
        }

        ListNode current = head;
        ListNode previous = null;

        while (current.next != null) {
            // 保存原来的下一个节点
            ListNode nextNode = current.next;

            // 反转连接
            current.next = previous;
            previous = current;
            current = nextNode;

            // 再次到达原头节点，说明有环
            if (current == head) {
                return true;
            }
        }

        return false;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(1)

## 踩过的坑

这个方法会修改原本的链表结构，并且没有恢复连接
