# 0160 · 相交链表

题目链接：https://leetcode.cn/problems/intersection-of-two-linked-lists

难度：简单 | 语言：Java | 标签：哈希表、链表、双指针

## 解题思路

最初我本来想用遍历的方法做，但是忽略了题目要求的是两个节点相等而不是两个节点的值相等。
长度对齐法让较长的链表先走完多出的部分，然后剩下的两个链表一个一个判断是否相等，输出第一个相等的节点

## 代码

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        int lengthA = 0;
        int lengthB = 0;

        ListNode pointerA = headA;
        ListNode pointerB = headB;

        // 统计链表 A 的长度
        while (pointerA != null) {
            lengthA++;
            pointerA = pointerA.next;
        }

        // 统计链表 B 的长度
        while (pointerB != null) {
            lengthB++;
            pointerB = pointerB.next;
        }

        // 统计结束后，两个指针都在 null，需要回到头节点
        pointerA = headA;
        pointerB = headB;

        // 让较长链表的指针先走长度差对应的步数
        while (lengthA > lengthB) {
            pointerA = pointerA.next;
            lengthA--;
        }

        while (lengthB > lengthA) {
            pointerB = pointerB.next;
            lengthB--;
        }

        // 剩余长度相同，两个指针一起向后走
        while (pointerA != pointerB) {
            pointerA = pointerA.next;
            pointerB = pointerB.next;
        }

        // 相交时返回共享节点；不相交时两者同时为 null
        return pointerA;
    }
}
```

## 复杂度

时间复杂度O(m+n)，空间复杂度O(1)
