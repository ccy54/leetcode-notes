# 0438 · 找到字符串中所有字母异位词

题目链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

难度：中等 | 语言：Java | 标签：哈希表、字符串、滑动窗口

## 解题思路

最初的想法：使用哈希表构造一个长度为p.length的窗口，从左往右遍历，若窗口内包含字符串p内的全部字符，则保存窗口第一个字母的下标。
经过提示之后，发现字符串内只包含小写字母，我们可以构造两个长度为26的数组来统计每个字符出现的次数，分别表示p内每个字符出现的次数和当前滑动窗口内每个字符出现的次数，这样就不用管每个字母具体出现的位置了，然后将滑动窗口内每个字符出现的个数和p内每个字符出现的个数进行对比，如果完全相符则是一个字母异位词。
优化：此时存储的是长度为26的数组，可以换成存储当前滑动窗口和p内部的差值，一个用++，一个用--，若有不为0的地方，则diff++



## 代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> result = new ArrayList<>();

        int windowSize = p.length();

        if (s.length() < windowSize) {
            return result;
        }

        int[] pCount = new int[26];
        int[] windowCount = new int[26];

        // 统计 p 和第一个窗口里的字符次数
        for (int i = 0; i < windowSize; i++) {
            pCount[p.charAt(i) - 'a']++;
            windowCount[s.charAt(i) - 'a']++;
        }

        if (Arrays.equals(pCount, windowCount)) {
            result.add(0);
        }

        // right 指向即将进入窗口的新字符
        for (int right = windowSize; right < s.length(); right++) {
            // 移除窗口最左侧的字符
            int outgoing = right - windowSize;
            windowCount[s.charAt(outgoing) - 'a']--;

            // 加入窗口右侧的新字符
            windowCount[s.charAt(right) - 'a']++;

            // 比较字符次数，记录新窗口的起点
            if (Arrays.equals(pCount, windowCount)) {
                int left = right - windowSize + 1;
                result.add(left);
            }
        }

        return result;
    }
}
```

## 复杂度

时间复杂度：O(m+(n−m)×Σ)，其中 n 为字符串 s 的长度，m 为字符串 p 的长度，Σ 为所有可能的字符数。我们需要 O(m) 来统计字符串 p 中每种字母的数量；需要 O(m) 来初始化滑动窗口；需要判断 n−m+1 个滑动窗口中每种字母的数量是否与字符串 p 中每种字母的数量相同，每次判断需要 O(Σ) 。因为 s 和 p 仅包含小写字母，所以 Σ=26。
空间复杂度：O(Σ)。用于存储字符串 p 和滑动窗口中每种字母的数量。
