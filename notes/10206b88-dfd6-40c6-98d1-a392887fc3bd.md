# 0234 · 回文链表

题目链接：https://leetcode.cn/problems/palindrome-linked-list/

难度：简单 | 语言：Java | 标签：栈、递归、链表、双指针

## 解题思路

这个方法的思路是通过递归找到链表的尾部，从链表的尾部层层递归从而和正常从链表头部往下比较。
check(N1)
  → check(N2)
    → check(N3)
      → check(N4)
        → check(N5)
          → check(N6)
            → check(null)，返回 true
使用if (currentNode != null)判断是否到达尾部，若到达则return true，然后递归内部开始从N6回溯到N1，而frontPointer是从正常顺序的链表，比较两个节点的值是否相等，若不相等，则if (currentNode.val != frontPointer.val) {
                return false;
            }返回false，回到外层，if (!recursivelyCheck(currentNode.next)) {
                return false;
            }此时外层也返回false，层层嵌套最终返回false。
节点3那层：发现 3 != 1，返回 false
    ↓
节点2那层：下一层返回 false，自己也返回 false
    ↓
节点1那层：下一层返回 false，自己也返回 false
    ↓
isPalindrome 最终得到 false


## 代码

```java
class Solution {
    private ListNode frontPointer;

    private boolean recursivelyCheck(ListNode currentNode) {
        if (currentNode != null) {
            if (!recursivelyCheck(currentNode.next)) {
                return false;
            }
            if (currentNode.val != frontPointer.val) {
                return false;
            }
            frontPointer = frontPointer.next;
        }
        return true;
    }

    public boolean isPalindrome(ListNode head) {
        frontPointer = head;
        return recursivelyCheck(head);
    }
}
```
