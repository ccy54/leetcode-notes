# 0141 · 环形链表

题目链接：https://leetcode.cn/problems/linked-list-cycle/

难度：简单 | 语言：Java | 标签：哈希表、链表、双指针、Floyd判圈算法

## 解题思路

使用快慢指针法，slow的步长为1，fast的步长1为2，判断fast和slow是否有相等的时候，若存在相等的时候则存在环，slow和fast移动的结束条件为当前节点为null或当前节点的next为null

## 代码

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            // 比较是否指向同一个节点，不是比较 val
            if (slow == fast) {
                return true;
            }
        }

        return false;
    }
}
```

## 复杂度

时间复杂度 O(n)，额外空间复杂度 O(1)，时间复杂度来自循环
