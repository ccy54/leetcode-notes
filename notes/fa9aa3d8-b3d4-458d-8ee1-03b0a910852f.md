# 0015 · 三数之和

题目链接：https://leetcode.cn/problems/3sum/

难度：中等 | 语言：Java | 标签：数组、双指针、排序

## 解题思路

一开始想到使用和两数之和一样的解法，外层嵌套一个循环，遍历所有的数，内部为一个哈希表用来找到和为当前数负数的两个值，但是这样无法解决重复问题。所以改成先排序，外层嵌套一个循环遍历全部的数，内层使用一个双指针，先分别指向排序后的数组的两端（剩余的数组是在当前值之后的数组），根据三个数值的和来判断指针的移动，如果大于0则右边指针左移，如果小于0则左边指针右移。剔除重复值的方式一个是对于固定值，若这个值和前面的值一样，就跳过当前值。另一个是对于相同的组合，在移动过程中，若出现当前值和之前值相同的情况，则跳过当前值。

## 代码

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);

        for (int i = 0; i < nums.length - 2; i++) {
            // 最小的数已经大于 0，后面不可能凑出 0
            if (nums[i] > 0) {
                break;
            }

            // 跳过重复的固定值，避免重复答案
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    left++;  // 和太小，尝试更大的数
                } else if (sum > 0) {
                    right--; // 和太大，尝试更小的数
                } else {
                    result.add(Arrays.asList(
                        nums[i], nums[left], nums[right]
                    ));

                    left++;
                    right--;

                    // 跳过刚刚使用过的重复值
                    while (left < right
                            && nums[left] == nums[left - 1]) {
                        left++;
                    }

                    while (left < right
                            && nums[right] == nums[right + 1]) {
                        right--;
                    }
                }
            }
        }

        return result;
    }
}
```

## 复杂度

时间复杂度为 O(n²)，固定值和内部的双指针
空间复杂度为 O(logn)，排序的空间复杂度

## 踩过的坑

一开始准备和两数之和一样使用哈希表，但是无法解决重复问题

## 我的收获
