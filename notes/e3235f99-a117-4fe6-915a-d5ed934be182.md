# 0002 · 两数相加

题目链接：https://leetcode.cn/problems/add-two-numbers

难度：中等 | 语言：Java | 标签：链表

## 解题思路

一开始本来我想用拆分链表的方式，后来发现如果数字太长，相加会超出int或者long格式的存储，直接在链表上进行操作更快

## 代码

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // 占位节点，方便追加结果；它不属于最终答案
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;

        int carry = 0;

        // 任一链表还有数字，或者还有进位，就继续计算
        while (l1 != null || l2 != null || carry != 0) {
            int x = (l1 != null) ? l1.val : 0;
            int y = (l2 != null) ? l2.val : 0;

            int sum = x + y + carry;
            carry = sum / 10;

            // 创建当前位的节点，接到结果链表末尾
            tail.next = new ListNode(sum % 10);
            tail = tail.next;

            // 输入链表移动到下一个节点
            if (l1 != null) {
                l1 = l1.next;
            }
            if (l2 != null) {
                l2 = l2.next;
            }
        }

        return dummy.next;
    }
}
```

## 复杂度

时间 O(max(m, n))；额外空间 O(1)，结果链表占用 O(max(m, n))

## 踩过的坑

准备将链表转换成常数进行计算

## 我的收获

类似于竖式加法，直接用链表进行计算
