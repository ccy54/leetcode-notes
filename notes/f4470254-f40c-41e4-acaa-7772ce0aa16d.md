# 0049 · 字母异位词分组

题目链接：https://leetcode.cn/problems/group-anagrams

难度：中等 | 语言：Java | 标签：数组、哈希表、字符串、排序

## 解题思路

将当前的字符串放进一个新字符串组，然后遍历剩下的字符串，如果是字母异位词则写入新的字符串组，并从旧字符串组中删除，用字符串的长度控制不会出现一个字母多次出现的情况，当一个字符串遍历后，再取出旧字符串组中的第一个字符串来遍历。
对于有重复字母出现的字符串，创建一个temp，赋值为abcc，然后和aabc一起遍历字母，如果有出现aabc中的字母，就删掉abcc中这个字母出现的第一个位置，这样可以吗？

## 代码

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        List<List<String>> result = new ArrayList<>();

        // 标记每个字符串是否已经加入某个组
        boolean[] used = new boolean[strs.length];

        for (int i = 0; i < strs.length; i++) {
            if (used[i]) {
                continue;
            }

            // 用当前字符串创建一个新组
            List<String> group = new ArrayList<>();
            group.add(strs[i]);
            used[i] = true;

            // 在后面的字符串中寻找字母异位词
            for (int j = i + 1; j < strs.length; j++) {
                if (!used[j] && isAnagram(strs[i], strs[j])) {
                    group.add(strs[j]);
                    used[j] = true;
                }
            }

            result.add(group);
        }

        return result;
    }

    // 按你的方法：找到一个字符，就从 temp 中删除一次
    private boolean isAnagram(String first, String second) {
        if (first.length() != second.length()) {
            return false;
        }

        StringBuilder temp = new StringBuilder(second);

        for (int i = 0; i < first.length(); i++) {
            char current = first.charAt(i);
            int position = temp.indexOf(String.valueOf(current));

            if (position == -1) {
                return false;
            }

            temp.deleteCharAt(position);
        }

        return temp.length() == 0;
    }
}
```
