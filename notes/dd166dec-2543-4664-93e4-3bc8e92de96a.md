# 0001 · 两数之和

题目链接：https://leetcode.cn/problems/two-sum/

难度：简单 | 语言：Java | 标签：数组、哈希表

## 解题思路

从前往后，计算目标值和当前值的差值，然后用这个差值在当前值之后的值里面去查找

## 代码

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        // 从前往后，依次选择当前数字
        for (int i = 0; i < nums.length; i++) {
            int difference = target - nums[i];

            // 只在当前数字后面查找差值
            for (int j = i + 1; j < nums.length; j++) {
                if (nums[j] == difference) {
                    return new int[]{i, j};
                }
            }
        }

        // 题目保证存在答案，正常情况下不会执行到这里
        return new int[0];
    }
}
```

## 复杂度

时间复杂度是 O(n²)，额外空间复杂度是 O(1)

## 踩过的坑

时间复杂度有点高

## 我的收获

使用哈希表的时间复杂度会降低很多，但是空间复杂度会提升
