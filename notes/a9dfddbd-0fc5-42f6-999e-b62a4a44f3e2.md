# 0019 · 删除链表的倒数第N个结点

题目链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list

难度：中等 | 语言：Java | 标签：链表、双指针

## 解题思路

这个方法的目的也是找到待删除节点的前一个节点，使用双指针，前一个指针比后一个指针快n步，然后两个指针同时以速度1前进，当前一个指针运行到null时，后一个指针运行到待删除节点。因此，我们同样创建一个dummy节点，让后一个节点从dummy节点开始，前一个节点从head开始，这样，当前一个节点运行到null时，后一个节点运行到待删除节点的前一个节点。

## 代码

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0, head);
        ListNode first = head;
        ListNode second = dummy;
        for (int i = 0; i < n; ++i) {
            first = first.next;
        }
        while (first != null) {
            first = first.next;
            second = second.next;
        }
        second.next = second.next.next;
        ListNode ans = dummy.next;
        return ans;
    }
}
```

## 复杂度

时间复杂度O(L)，空间复杂度O(1)，时间复杂度主要来源于遍历链表
